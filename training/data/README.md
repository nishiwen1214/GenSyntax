# Training data

Place the training corpora in this directory:

- `gensyntax_cpt.jsonl`: continued pre-training records with a `text` field;
- `gensyntax_sft.jsonl`: supervised records with `instruction`, `input` and `output` fields.

For a versioned data release, record row counts, source accessions, split
rules, deduplication and leakage checks, licenses and SHA-256 checksums.
