# Microbial phenotype prediction

This directory contains the unified workflow for the ten microbial phenotypes
reported in the manuscript. It replaces the duplicated, phenotype-specific
development scripts with one versioned implementation and one declarative task
configuration.

The corresponding ten cleaned phenotype tables are included under
[`Data/BacDive/`](https://github.com/nishiwen1214/GenSyntax/tree/main/Data/BacDive).
The evaluation reads these local files and does not download data at runtime.

## Reported tasks

| Key | Phenotype | Encoding |
|---|---|---|
| `cell_shape` | Cell shape | 20 observed cleaned labels in the released table |
| `gram_stain` | Gram staining result | positive, negative or variable |
| `indole_test` | Indole test | positive or negative |
| `motility` | Cell motility | motile or non-motile |
| `multicellular_complex` | Multicellular complex formation | present or absent |
| `oxygen_tolerance` | Oxygen tolerance | cleaned BacDive category |
| `voges_proskauer` | Voges–Proskauer test | positive or negative |
| `optimal_temperature` | Optimal temperature | `<20`, `20–40` or `>40 °C` |
| `cell_length` | Cell length | `≤2` or `>2 µm` |
| `cell_width` | Cell width | `≤0.5` or `>0.5 µm` |

Scalar ranges are represented by their midpoint before discretization.
Ambiguous positive/negative labels such as `+/-` and missing labels are
excluded. To reproduce the supplied analysis scripts, classes represented by
fewer than five rows in the phenotype table are removed before matching; the
first phenotype label encountered for a species is retained when duplicate
rows disagree; and a species is matched when its name occurs in the embedding
`Source` field.

## Input embeddings

The embedding file must be a UTF-8 JSON array. Each record requires an
organism name and one finite, fixed-dimensional genome embedding:

```json
[
  {
    "Source": "Escherichia coli strain K-12",
    "products_embedding": [0.012, -0.031, 0.147]
  }
]
```

Alternative field names can be selected with `--source-field` and
`--embedding-field`. At most one embedding is used per species. The matching
table and train/test assignments are written to the output directory for
auditing.

The default compatibility behavior can be tightened with
`--conflict-policy exclude` (or `error`) and `--match-policy prefix`. The
diagnostics file records conflicts, unmatched species, class counts and species
with more than one candidate embedding match.

## Running the complete experiment

```bash
python phenotype_prediction/run_phenotype_prediction.py \
  --embeddings /path/to/merged_embeddings.json \
  --embedding-name GenSyntax \
  --data-dir Data/BacDive \
  --phenotypes all \
  --seeds 42 43 44 \
  --test-size 0.2 \
  --min-class-size 5 \
  --output-dir outputs/phenotype_prediction/gensyntax \
  --plot
```

The workflow evaluates logistic regression, random forest, support vector
machine, gradient boosting and a multilayer perceptron. For each random seed,
all five models use the same stratified 80:20 split. Feature scaling is fitted
only on the training partition. Results include accuracy, weighted precision,
weighted recall and weighted F1. `summary_metrics.csv` reports the mean and
sample standard deviation across the three independent seeds.

To evaluate another embedding model, rerun the same command with its embedding
file and a distinct `--embedding-name` and `--output-dir`. Do not combine
results obtained from different species sets without explicitly reporting the
sample counts and matching diagnostics.

## Outputs

- `per_seed_metrics.csv`: metrics for every phenotype, model and seed;
- `summary_metrics.csv`: mean and standard deviation across seeds;
- `split_assignments.csv`: species-level train/test membership;
- `test_predictions.csv`: sample-level predictions for error analysis;
- `data_diagnostics.json`: filtering, matching and class-count audit trail;
- `phenotype_performance.pdf`: optional summary plot generated by `--plot`.

## Scope of the consolidation

The supplied development bundle also contained pathogenicity, plasmid
presence, flagellar arrangement, hemolysis, methyl-red, optimal-pH and
continuous regression experiments. These are not among the ten phenotypes
reported in the revised manuscript and are therefore not part of this
reproduction entry point. The continuous cell-length, cell-width and
temperature scripts were also excluded because the manuscript reports their
predefined classification versions.

## Data consistency note

The released oxygen-tolerance table currently contains eight non-null
categories. The manuscript lists nine categories, including
`microaerotolerant`, which is not present in this table. This discrepancy
should be reconciled against the exact analysis dataset before publication;
the workflow does not manufacture an unobserved class.
